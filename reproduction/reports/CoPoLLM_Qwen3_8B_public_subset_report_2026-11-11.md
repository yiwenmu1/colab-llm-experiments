# CoPoLLM Qwen3-8B 公开子集分类复现报告

本报告覆盖作者公开 LoRA 与关闭 adapter 的 Qwen3-8B 基座在同一公开测试子集上的分类对照。
未训练 CPRL、PRO 或 DSCO，未调用教师 API，未评测成批回复生成质量。不能视为论文原测试集效果或完整训练方法复现。

## 本轮结论

本轮公开子集分类评测已完成，两组各 981 条；完整覆盖、唯一键、金标及各类别支持数均通过核验，独立 sklearn 重算一致。

- 作者 LoRA 的 Macro F1 从 0.2670 提升到 0.3386，绝对增加 0.0716（7.16 个百分点）；Micro F1 从 0.3367 提升到 0.4647。八类中七类 F1 提高，“应该句式”下降。
- 安全风险结果没有显示改善。42 条高危样本中，基座漏判 22 条，作者 LoRA 漏判 25 条；HRMDR 从 52.38% 上升到 59.52%，多漏判 3 条。作者 LoRA 将其中 23 条判为中危，另 2 条没有有效风险字段。这是当前样本的观察结果，不能外推总体临床安全性。
- 基座 981 条均达到 128-token 上限，作者 LoRA 无输出达到上限。基座可先输出分类字段再继续解释或重复任务；因此“达到上限”与“分类无法解析”必须区分。
- 基座 67 条、作者 LoRA 42 条未满足固定解析格式。作者 LoRA 的这些输出缺少三项分类字段，抽查可见转为自然治疗回复，提示联合任务的切换仍不稳定。
- 本轮证实了发布权重在当前协议下的分类收益，但没有复现“安全风险识别也更好”的结论；也不能据此宣称复现了论文原表、CPRL 或 DSCO 训练效果。

## 数据与完整性

测试对话 324；有效标注 981；排除无效标注 41；高危 42。
两组共 1962 条预测，逐一核对样本唯一键、金标和类别支持数，覆盖完整。
未标注发言不作为无偏差负样本；公开有效样本无法完整检验多标签或无偏差识别能力。

## 固定协议

Qwen/Qwen3-8B；NF4 4-bit、double quant、FP16 计算；batch=1；输入上限 2048；输出上限 128；greedy。
两组使用仓库同一任务模板与 tokenizer；基座为关闭作者 adapter 的受控对照，不等同于其官方 chat template 最优效果。
输入保留当前发言和此前历史，不纳入当前目标回复或金标 annotation。超长历史按轮次移除。
沿用首次 v1 协议，没有根据测试分数调整提示或输出长度。

## 解释边界与问题

- 基座小样本输出存在分类字段后继续解释、重复任务提示的行为。达到 token 上限不能单独证明分类字段缺失；上表同时保留格式失败与长度上限指标。
- HRMDR 是金标高危样本中未预测为高危的比例（越低越好），仅 42 条，每漏一条约改变 2.38 个百分点。
- Macro F1 为固定八类的多标签指示矩阵宏平均。格式失败不能静默剔除；解析得到的标签保留计分。
- 公开子集、量化、模板和上下文条件与论文原评测可能不同，不用论文参考值作为本子集验收线。
- v1 由此前 A100、短时 T4 和本轮 A100 分轮续跑得到。模型 revision 与推理协议保持一致，但 PyTorch 和 GPU 环境存在变化，实际记录以各轮 environment/provenance 为准；跨轮数值完全一致性未另行验证。
